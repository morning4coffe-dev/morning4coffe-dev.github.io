# Morning4coffe website

Static GitHub Pages site for Morning4coffe and its applications.

Published routes:

- <https://morning4coffe-dev.github.io/>
- <https://morning4coffe-dev.github.io/fluestic/>
- <https://morning4coffe-dev.github.io/storylines/>
- <https://morning4coffe-dev.github.io/recurrents/>

The site intentionally has no build step, runtime API calls, analytics, or
third-party UI dependencies. GitHub Pages serves the committed HTML, CSS, and
local artwork directly from the repository root.
