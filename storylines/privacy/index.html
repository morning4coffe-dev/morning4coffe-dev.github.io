Privacy

Storylines uses a telemetry provider to collect anonymous usage and crash information. Story content is not intentionally collected.

Telemetry helps improve stability, prioritize fixes, and understand which workflows are used most often. The underlying provider may change over time.

Application and session data

  • App version and anonymous session identifier
  • Activation type, first-run state, launch count, and app uptime
  • Current editor mode
  • Settings state, including theme, autosave, dialogue mode, experimental features, and review prompt state

Project summary data

  • Whether a project is currently open and whether unsaved progress exists
  • Chapter, character, plot thread, and branching dialogue counts
  • Branching dialogue node and choice counts

Feature interaction data

  • Review prompt and in-app banner interactions
  • Microsoft Store update availability notifications
  • Focus Mode configuration and completion state
  • Project statistics dialog opens

Crash diagnostics

  • Exception type and message, and whether an inner exception exists
  • Available memory and project summary counts at the time of the error
  • Unsaved progress state

Operating system data

  • Device architecture and family
  • Windows build and language

Contact

Privacy questions can be submitted through Storylines support on GitHub.
