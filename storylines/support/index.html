Help with Storylines

Support

Report bugs or request features through the Storylines issue tracker.

Before opening an issue

  • Install the latest Microsoft Store version.
  • Include your Windows and Storylines versions.
  • Describe whether the problem occurs in a new project or only an existing file.
  • List the exact steps that reproduce the issue.

Protect your manuscript

Do not attach private story content unless it is essential and you are comfortable sharing it publicly. A minimal sample project is usually best.

Contributing

Storylines is open source. Code contributions, translations, bug reports, and feature requests are welcome.
