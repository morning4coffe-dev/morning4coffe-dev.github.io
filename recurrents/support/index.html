Help with Recurrents

Support

Report a problem or request a feature through the Recurrents issue tracker.

Before opening an issue

  • Install the latest Microsoft Store version.
  • Include your operating system and Recurrents versions.
  • Describe whether Microsoft sign-in and OneDrive sync are enabled.
  • List the exact steps that reproduce the issue.

Protect account information

Never include Microsoft account credentials, authentication tokens, or private OneDrive data in a public issue. Redact personal subscription details from screenshots when they are not needed.

Build or contribute

Recurrents is developed in public. Contributions are welcome when they are coordinated through an existing or approved issue.
